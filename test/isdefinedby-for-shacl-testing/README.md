The directory contains generated SHACL shape artefacts demonstrating the effect of the `annotateShaclConceptsWithOntology` configuration parameter (in *config-parameters.xml*).

The *annotateShaclConceptsWithOntology-enabled* directory shows the output when the parameter is set to `true()`, and *annotateShaclConceptsWithOntology-disabled* shows the output when it is set to `false()`.
